# Controller Helper for PC

Small Windows utility that lets you use a Steam Controller as a general-purpose gamepad outside of Steam. Maps touchpads, triggers, and gyro to standard XInput so non-Steam games, DAWs, and desktop apps see it as a regular controller.

## Download

Grab the latest build here: **[SteamControllerPC.zip](../../releases/latest/download/SteamControllerPC.zip)**

Unpack the archive and run the installer inside.

## What it does

- Steam Controller → XInput mapping (works outside Steam)
- Custom profiles per game or per app
- Gyro aim, trackpad scrolling, click-wheel rebinds
- No background services after install

## Requirements

- Windows 10 or 11 (64-bit)
- Steam Controller connected via USB dongle or Bluetooth
